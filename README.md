# A/B-тест лендинга (290k+ пользователей)

## Описание проекта
В проекте проанализированы результаты A/B-теста нового дизайна лендинга.  
Цель — определить, влияет ли изменение дизайна на конверсию пользователей и можно ли рекомендовать его к внедрению.

В работе сделан акцент не только на проверке статистической значимости, но и на качестве данных, корректности эксперимента и формировании продуктовых рекомендаций.

---

## Гипотеза
**H₀:** Новый дизайн лендинга не влияет на конверсию.  
**H₁:** Новый дизайн лендинга увеличивает конверсию.

---

## Данные
- ~290 000 пользователей
- Пользовательский уровень данных:
  - экспериментальная группа (control / test)
  - версия страницы
  - факт конверсии
  - временная метка события

Перед анализом данные были тщательно проверены и очищены.

---

## Подготовка данных
- Удалены пользователи с несоответствием группы и версии страницы
- Удалены дубликаты пользователей
- Проверен баланс групп
- Проверено распределение конверсий

---

## Анализ
- Расчёт конверсии в контрольной и тестовой группах
- Проверка гипотезы с помощью **Z-test для пропорций**
- Дополнительный временной анализ:
  - по дням
  - по часам
- Поиск аномалий и внешних факторов

---

## Результаты
- **Конверсия control:** 12.04%
- **Конверсия test:** 11.88%
- **p-value:** 0.19

Статистически значимого эффекта не обнаружено.

---

## Выводы и рекомендации
- Новый дизайн лендинга не показывает статистически значимого улучшения конверсии.
- Рекомендовано **не внедрять** изменения.
- Проведен дополнительный анализ по дням и часам
